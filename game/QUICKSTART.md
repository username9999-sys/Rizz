# Quickstart: game

Node.js / JavaScript module.

## Install

```bash
cd game
npm install
```

## Run

```bash
node index.js
```

## Test

```bash
npm test
```

## Configuration

- Environment variables: see any `.env.example` in this directory.
- Entry point: `index.js`.
- Version: `?`.

## Common commands

```bash
# Format
npx prettier --write .

# Lint
npm run lint   # if defined
```
