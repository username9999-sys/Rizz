# Quickstart: social-media

Node.js / JavaScript module.

## Install

```bash
cd social-media
npm install
```

## Run

```bash
node server.js
```

## Test

```bash
jest
```

## Configuration

- Environment variables: see any `.env.example` in this directory.
- Entry point: `server.js`.
- Version: `1.0.0`.

## Common commands

```bash
# Format
npx prettier --write .

# Lint
npm run lint   # if defined
```
