# Quickstart: crm

Node.js / JavaScript module.

## Install

```bash
cd crm
npm install
```

## Run

```bash
node src/api/index.js
```

## Test

```bash
jest
```

## Configuration

- Environment variables: see any `.env.example` in this directory.
- Entry point: `src/api/index.js`.
- Version: `1.0.0`.

## Common commands

```bash
# Format
npx prettier --write .

# Lint
npm run lint   # if defined
```
