# Quickstart: discord-bot

Node.js / JavaScript module.

## Install

```bash
cd discord-bot
npm install
```

## Run

```bash
node index.js
```

## Test

```bash
jest
```

## Configuration

- Environment variables: see any `.env.example` in this directory.
- Entry point: `index.js`.
- Version: `1.0.0`.

## Common commands

```bash
# Format
npx prettier --write .

# Lint
npm run lint   # if defined
```
