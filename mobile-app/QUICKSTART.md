# Quickstart: mobile-app

Node.js / JavaScript module.

## Install

```bash
cd mobile-app
npm install
```

## Run

```bash
expo start
```

## Test

```bash
jest
```

## Configuration

- Environment variables: see any `.env.example` in this directory.
- Entry point: `node_modules/expo/AppEntry.js`.
- Version: `1.0.0`.

## Common commands

```bash
# Format
npx prettier --write .

# Lint
npm run lint   # if defined
```
