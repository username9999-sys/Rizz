# Quickstart: chat-app

Node.js / JavaScript module.

## Install

```bash
cd chat-app
npm install
```

## Run

```bash
react-scripts start
```

## Test

```bash
react-scripts test
```

## Configuration

- Environment variables: see any `.env.example` in this directory.
- Entry point: `index.js`.
- Version: `1.0.0`.

## Common commands

```bash
# Format
npx prettier --write .

# Lint
npm run lint   # if defined
```
